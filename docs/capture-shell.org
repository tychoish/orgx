#+title: Orgx Capture Shell Guide
#+author: tychoish
#+language: en

The Orgx Capture Shell (=orgx-capture-shell.el=) provides a continuous, non-modal REPL for logging notes, tasks, and journal entries into Org mode buffers without interrupting active window configurations.

* Quickstart

1. Toggle the capture shell popup window:
   - Key: =C-c o C-s= or =C-c o c s=
   - Command: ~M-x orgx-capture-shell-toggle~
2. Open the transient menu:
   - Key: =C-c o C-t= or =C-c o c C-t=
   - Command: ~M-x orgx-capture-shell-transient~

* Architecture & Features

** 1. Dedicated Popup Window
The capture shell resides in a buffer named =*orgx-capture-shell*= and is automatically routed to a 15-line bottom popup window via ~display-buffer-alist~:
#+begin_src elisp
(display-buffer-reuse-window display-buffer-at-bottom)
#+end_src
Invoking ~orgx-capture-shell-toggle~ hides the window if it is currently active, or displays and focuses it if hidden.

** 2. Cascading Target Resolution
When logging an entry, the target file and headline are resolved via ~orgx-capture-shell-target-directory-alist~:
#+begin_src elisp
(setq orgx-capture-shell-target-directory-alist
      '(("~/src/project-a" . ("notes.org" . "Tasks"))
        ("~/src/project-b" . "inbox.org")
        ("^/tmp/.*" . ("scratch.org" . "Scratch"))))
#+end_src
If no directory pattern matches, it falls back to ~orgx-capture-shell-default-file~ (=agentic.org=) and ~orgx-capture-shell-default-headline~ (=Tasks=).

** 3. Slash Commands
Within the REPL buffer, slash commands allow dynamic reconfiguration:
- =/target [file[:headline]]= :: Switch target file and headline on the fly.
- =/template [task|note|journal|plain]= :: Switch active template formatting.
- =/denote= :: Interactively pick a Denote note as the capture target.
- =/undo= :: Roll back the most recently captured item.
- =/recent= or =/list= :: List recently captured items in the session.
- =/clear= :: Clear the REPL scrollback.
- =/help= :: Display inline command reference.

** 4. Capture Form
Plain input is captured immediately. To fill in more than a title, open the form:
- End the line with the trigger (=orgx-capture-shell-form-trigger=, default =;=), e.g. =buy milk;=
- Or press =C-RET= on the current input (even if empty); terminal frames often can't send =C-RET=, so use the trigger or =/form= there
- To capture text that really ends in the trigger, double it: =int x = 1;;= captures =int x = 1;=
- Or use =/form [title]= / ~M-x orgx-capture-shell-form~

The form asks for title, template, target file, headline (completing over the file's outline paths) and an optional body, then captures once without changing the shell's current target. Set =orgx-capture-shell-form-style= to =transient= to edit the fields in a transient menu instead (=c= captures).

** 5. Nested Targets
Headlines may be outline paths separated by =orgx-capture-shell-headline-separator= (default =/=), e.g. =/target notes.org:Projects/Tasks=. Each segment is searched inside the previous one; missing segments are created with correct nesting. Captured headings are re-leveled to be children of the target, so captures never land as stray top-level headings.

** 6. Completion at Point
Slash commands, =/template= names, and =/target= files and headlines (after the =:=) complete with =completion-at-point= and Corfu.

** 7. Prompt
The prompt shows target and template: =orgx-capture [agentic.org:Tasks|task]>=.

** 8. HUD
=hud-dispatch= lists the shell toggle (=o s=) and the capture form (=o f=) under org-mode.

** Known limits
- Headline names containing the separator (=/=) can't be addressed as a single path segment; set =orgx-capture-shell-headline-separator= to another string.
- A headline containing => = confuses prompt detection for completion; avoid it in target headlines.
- =/undo= removes the captured entry but leaves any parent headings that capture created.
- The form's body is a single line.
