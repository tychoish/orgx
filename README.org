Org mode extensions, structured capture templates, continuous REPL capture shell, and native command-line tooling for Emacs.

* Overview

=orgx= is a dual-stack monorepo providing structured Org mode extensions and tooling:
- *Emacs Lisp Suite (=lisp/=)*:
  - =orgx.el=: Core Org conveniences, unified global (=C-c o=) and minor-mode (=C-c o c=) keymaps, and structured navigation.
  - =orgx-capture.el=: Structured capture template generator DSL with customizable default files.
  - =orgx-capture-shell.el=: Non-modal comint REPL capture shell displayed in a dedicated 15-line bottom popup window.
  - =orgx-denote.el=: Optional Denote integrations (agenda views, signature sorting, subtree extraction).
- *Rust CLI (=crates/orgx-cli/)*:
  - High-performance command-line client built on =sprite-direct= and =reedline= for one-shot piping and interactive terminal capture outside Emacs.

* Building & Testing

The repository relies on zero ad-hoc shell scripts. All operations run directly in Emacs via ~builder.el~ or via standard underlying command-line tools.

** In Emacs (via ~builder.el~)
- ~M-x builder~ or ~(builder-select)~ discovers all project candidates interactively.
- Centralized programmatic execution via ~(builder-select <target> :force t)~:
  - =(builder-select 'test :force t)= :: Runs the active test suite (e.g., workspace cargo test or ERT tests).
  - =(builder-select 'build :force t)= :: Runs the workspace build.
  - =(builder-select 'clippy :force t)= :: Runs clippy linting across workspace crates.
  - =(builder-select 'rust-test-workspace :force t)= :: Runs specific target symbol.
- MCP client & Agent integration:
  - ~discover_tasks~ returns structured candidates with stable =:id= and =:action= tags.
  - ~run_task(target="test")~ or ~run_task(id="rust-test-workspace")~ executes compilation without prompts.

** From Command Line (Direct Tooling)
- *Generate Autoloads*:
  #+begin_src bash
  emacs -Q --batch --eval '(loaddefs-generate "lisp" "lisp/orgx-loaddefs.el")'
  #+end_src
- *Byte-compile Elisp*:
  #+begin_src bash
  emacs -Q --batch -L lisp -f batch-byte-compile lisp/*.el
  #+end_src
- *Run ERT Unit Tests*:
  #+begin_src bash
  emacs -Q --batch -L lisp -L test \
    -l test/orgx-test.el \
    -l test/orgx-capture-test.el \
    -l test/orgx-capture-shell-test.el \
    -l test/orgx-denote-test.el \
    -f ert-run-tests-batch-and-exit
  #+end_src
- *Cargo Workspace (Rust)*:
  #+begin_src bash
  cargo check --workspace
  cargo test --workspace
  cargo build --workspace --release
  #+end_src
