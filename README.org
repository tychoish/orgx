Org mode extensions, structured capture templates, continuous REPL capture shell, and native command-line tooling for Emacs.

* Overview

=orgx= is a dual-stack monorepo providing structured Org mode extensions and tooling:
- *Emacs Lisp Suite (=lisp/=)*:
  - =orgx.el=: Core Org conveniences, unified global (=C-c o=) and minor-mode (=C-c o c=) keymaps, and structured navigation.
  - =orgx-capture.el=: Structured capture template generator DSL with customizable default files.
  - =orgx-capture-shell.el=: Non-modal comint REPL capture shell displayed in a dedicated 15-line bottom popup window.
- *Rust CLI (=crates/orgx-cli/)*:
  - High-performance command-line client built on =sprite-direct= and =reedline= for one-shot piping and interactive terminal capture outside Emacs.

* Documentation

- [[file:docs/capture-shell.org][Orgx Capture Shell Guide]]: In-depth guide to the non-modal capture shell, target resolution cascade, popup window rules, and slash commands.
- [[file:docs/cli.org][Orgx CLI & Terminal REPL]]: Guide to the native Rust CLI binary, single-shot capture, Sprite protocol connection, and Reedline terminal REPL.

* Keybindings

| Key Sequence  | Command                         | Description                                      |
|---------------+---------------------------------+--------------------------------------------------|
| =C-c o C-s=   | ~orgx-capture-shell-toggle~     | Toggle 15-line bottom popup capture shell buffer |
| =C-c o c s=   | ~orgx-capture-shell~            | Open/focus capture shell buffer directly         |
| =C-c o C-t=   | ~orgx-capture-shell-transient~  | Open transient capture modal menu                |
| =C-c o c C-t= | ~orgx-capture-shell-transient~  | Open transient capture modal menu from capture   |

* Building & Testing

All actions can be invoked directly with standard tools or via the helper scripts under =scripts/=:

** Emacs Lisp
- Byte-compile:
  #+begin_src bash
  ./scripts/compile-elisp.sh
  # or directly:
  emacs -Q --batch -L lisp -f batch-byte-compile lisp/*.el
  #+end_src
- ERT Tests:
  #+begin_src bash
  ./scripts/test-elisp.sh
  # or directly:
  emacs -Q --batch -L lisp -L test -l ert -f ert-run-tests-batch-and-exit
  #+end_src

** Rust CLI
- Build binary:
  #+begin_src bash
  ./scripts/build-cli.sh
  # or directly:
  cargo build --release -p orgx-cli
  #+end_src
- Test:
  #+begin_src bash
  ./scripts/test-cli.sh
  # or directly:
  cargo test --workspace
  #+end_src
